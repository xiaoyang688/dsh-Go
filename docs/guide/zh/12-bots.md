# DS Bot

DS Bot 是主机上的插件，每个 Bot 有自己的职责、对话和记忆。连接支持 DS Bot 的主机后，从对话抽屉的筛选栏下方打开 DS Bot。切换对话筛选或工作区时，入口仍可见。也可从「全部功能」进入，或点[打开](dshgo://open/ds-bot)。页面顶部显示主机名称，下方先列群聊，再列 Bot。

## 手机端支持

如果显示**DS Bot 暂不支持手机端**，说明这台主机上的 DS Bot 还没有可用的手机接口。可以点**在网页版打开**先使用 DSH Web；主机上的插件更新并重启后，点**重试**重新检查。这里不表示 Bot 或群聊已经被删除。

未检测到 DS Bot 时，页面提供安装入口或在电脑上执行的安装命令。若主机上的 DSH Remote 已提供 DS Bot 接口，连接后可从「全部功能」打开 DS Bot。只提供请求接口的主机会通过定期读取来更新 Bot 和群聊状态。若主机未提供相应接口，可以通过 SSH 连接，或在电脑上使用 DSH Web。

## 整理群聊和 Bot

主机支持布局保存时，在 DS Bot 首页的 Bot 区域点「编辑组织」。长按群聊或 Bot 的拖动把手调整顺序。通过「⋮」菜单可以把 Bot 移到其他目录。DS Bot 首页的 Bot 区域将主 Bot 固定在顶部，其他 Bot 放在默认收起的目录中，点目录名称即可展开。点「保存」后，连接同一台主机的兼容 DSH Go 客户端会读取这份布局。

主机安装独立的 DSH Go Layout 插件后，目录和排序由该插件保存。如果此前使用 DS Bot 布局扩展，先在 DS Bot 首页点「复制 DS Bot 布局」，等应用确认复制成功后，再换回官方 DS Bot。

## 群聊目标

打开群聊，点顶部的详情入口，再点「群聊目标」。选择「设定目标」，填写要达成的结果，然后点「发送目标请求」。群管理员会在群聊里与你对齐目标和验收条件。目标开始后，可以在同一页查看进度，并按当前状态暂停、继续或停止目标。

## 发送图片

在 Bot 或群聊的输入框旁点「＋」，再从相册选择图片或拍照。发送前可以预览或移除图片。可以附上文字，也可以只发图片。主机需要支持 DS Bot 图片消息。历史消息包含图片附件时，可以点缩略图查看。Bot 回复中的工作区图片由主机按该对话的文件访问权限提供。

## 使用 Skill

在使用主机原生引擎的 Bot 私聊中，从输入框旁打开技能列表，选择当前对话可用的 Skill。应用会把 `/技能名` 加到草稿中。补充任务后点发送，主机就会按该 Skill 处理请求。

## 工作目录

打开一个 Bot 或群聊的对话，点顶部的详情入口，再点**工作目录**。这里选择的是已连接主机上的目录；远程主机的目录不在手机上。

1. 查看**当前目录**，从主机给出的目录列表里选择。
2. 点**保存**，核对「使用此工作目录？」里显示的目录，再点**保存**。

Bot 可以选**团队工作区**恢复默认。群聊可以选**每位 Bot 各自的目录**，让成员按各自的工作目录工作。

如果提示连接或目录已变化，关闭弹层后重新打开。主机拒绝某个目录时，它可能已不存在、无法访问或受保护；另选目录或重试。

## 复制 Bot

在 Bot 的详情页点**复制 Bot**，阅读说明后确认。新 Bot 沿用职责、指令和模型设置，对话与个人记忆从头开始，名称由主机分配；模型可用时，它会先发一句问候。

复制成功后通常会打开新 Bot。若提示已复制、稍后出现在列表，回到 DS Bot 列表查看，不必再复制一次。连接断开、切换主机或只读时，先恢复连接，再重新打开详情操作。
